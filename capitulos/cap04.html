O destino de Ademar

o Ademar usou vassouras para retirar os resíduos que sobraram utilizando a garrafa pet como recipiente para o descarte correto. Após essas ações, poderia usar como treinamento secretos para evitar situações como essa no futuro. Dando-se o treinamento secreto, irá ensinar os outros sobreviventes como evitar esse tipo de situação com algo radioativo.

Apareceu um gato que descobriu aonde estava os recipientes e acabou derrubando os recipientes que foram separados de uma forma totalmente incorretas. Apareceram os sobreviventes que havia sido treinado pelo Ademar para refazer o que ele fez.

Os sobreviventes aplicaram o mesmo que o Ademar ensinou com o treinamento secreto dele, repetindo da mesma forma: usou as vassouras para varrer os restantes de resíduos que escaparam das garrafas pets e descobriu a causa que as tampas dos recipientes estavam "mal fechada" e totalmente negligenciada. Usando de forma correta os recipientes, os sobreviventes garantiram o descarte correto separados de uma maneira totalmente eficaz.
